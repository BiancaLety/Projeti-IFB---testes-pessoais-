DOCUMENTAÇÃO DO SISTEMA F&F IMPORTS

Este projeto consiste em uma plataforma de catálogo digital para a loja F&F Imports, focada na exibição de produtos eletrônicos e acessórios, 
facilitando a conversão de vendas através do redirecionamento direto para o WhatsApp.

🚀 Começando
Essas instruções permitirão que você obtenha uma cópia do projeto em operação na sua máquina local para fins de desenvolvimento e teste.

📋 Pré-requisitos
Para rodar este projeto, você precisará de:

Um navegador web atualizado (Chrome, Firefox ou Edge).

Editor de código (Recomendado: VS Code).

Extensão Live Server no VS Code (para visualizar as alterações em tempo real).

Conexão com a internet (para carregar o framework Bootstrap via CDN).

🔧 Instalação

1 - Clone o repositório:

	Bash
	git clone https://github.com/seu-usuario/f-f-imports.git

2 - Navegue até a pasta do projeto:

	Bash
	cd f-f-imports

3 -Abra o projeto no VS Code:

	Bash
	code .

4 - Execute o projeto:
Clique com o botão direito no arquivo index.html e selecione "Open with Live Server".
